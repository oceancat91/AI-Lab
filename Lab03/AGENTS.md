# Agent 实验执行规范（作业三 · 图像分类）

适用范围：`Lab03/` 及其子目录。与仓库根规范共同执行。

1. 每次实验前完整阅读仓库根 `AGENTS.md`、本文件和 `WORKFLOW.md`，确认阶段与前置验收。
2. 优先级：用户当前指示 > 有证据的最新课程通知 > 本目录原始 PDF > WORKFLOW > 本文件。不得把题面示例代码当作必须照抄的实现。
3. 官方 50,000 张训练图像先按类别划分 45,000/5,000；官方 10,000 张测试图像封存至阶段 6。
4. 均值、标准差只在 45,000 张训练子集计算；增强只作用于训练批次。验证与测试使用同一确定性变换。
5. 在首次训练前冻结实验矩阵、训练轮数、种子、评价指标、选模和同分规则；不得查看测试结果后改模型。
6. 采用 2×2 因子实验时明确声明两个因素；解释单因素作用时只比较相邻的、仅差一项的配置。
7. 基线必须先跑通。所有配置共用数据加载、训练、验证、计量入口；架构差别不得夹带优化器或数据变化。
8. 只使用 conda 管理依赖，不用 pip；环境定义与实际版本锁文件同步。不得修改其他实验环境。
9. 随机源从 `config.py` 派生并记录。数据顺序和增强使用独立随机数生成器，避免架构差异改变样本顺序。
10. 记录数据校验值、划分指纹、代码指纹、环境、参数、逐轮 loss/accuracy、耗时、最佳轮次及运行状态。
11. 报告所有已注册配置，保留不利结果。单次种子实验不得宣称统计显著或跨种子稳定。
12. “每类准确率”定义为该真实类别的正确数/该类样本数（即类别召回率）；混淆矩阵行是真值、列是预测。
13. 训练曲线须区分在线训练指标（训练模式，可能增强）与验证指标（评估模式）；最佳检查点额外评估无增强训练集。
14. 测试集仅评估由验证集确定的一个最终检查点。测试误例与 Grad-CAM 为事后分析，不用于再次选模。
15. 不伪造实验结果、引用、视觉检查或复现记录；区分实测、解释假设和未验证事项。
16. 每阶段运行 `python check_rigor.py --stage N`，有 ERROR 则修复后重跑。不得删检查或降低阈值来掩盖失败。
17. 检查器新增判定需有反向测试。自检不能替代图像目视核查、方法讨论和完整重训。
18. 仅使用相对路径；原始数据、缓存、环境和检查点留在忽略目录，不推送模型文件和大数据。
19. 公开提交前检查暂存文件、隐私、文件大小和差异；保留课程原文的字节一致副本。
20. 用户已明确授权推送指定仓库；常规实现、实验、修复、提交与推送不再重复请求确认。
21. GitHub 推送与课程坚果云提交是不同操作；未经实际上传，不得声称已向课程提交。
